# 🎯 SkillBridge — Labour-Market Intelligence & Curriculum-Alignment Platform

## SIH 2026 Problem Statement #26134

> **"Challenges in aligning skill development programs with industry requirements and emerging job market demands"**
> — Government of Maharashtra, Dept. of Skills, Employment, Entrepreneurship & Innovation

---

## PS Requirement → Feature Mapping

Every single PS requirement is mapped to a specific feature in our platform:

| PS Requirement | Page | Feature |
|----------------|------|---------|
| Job-posting signals | 📊 P1, 🤖 P2 | AI-extracted skills from job postings, trend charts |
| Employer surveys / validation | 💡 P4 | Employer feedback panel with approve/reject + comments |
| Industry consultations | 🤖 P2 | Paste any industry requirement → AI extracts structured demands |
| Sector growth data | 📊 P1 | Sector-wise growth charts, district-wise demand heatmap |
| Placement outcomes | 📊 P1 | Placement rate tracking by program, district, year |
| Emerging-technology trends | 📊 P1 | Trending/emerging skills with growth %, declining skills flagged |
| Identify demand by role, skill, location, proficiency | 📊 P1 | District-wise demand breakdown with role + skill + level filters |
| Map skill gaps to qualifications & courses | 🔍 P3 | Side-by-side: industry skills vs course skills with gap matrix |
| Recommend curriculum updates | 💡 P4 | AI-generated recommendations: update course, add module, etc. |
| Flag obsolete or oversupplied courses | 💡 P4 | Courses with declining demand or excess capacity flagged in red |
| Support employer validation | 💡 P4 | Employer approve/reject with comments, validation status tracking |
| Generate district-level training plans | 📊 P1 | District-wise recommended program mix based on local industry |
| Stronger placement rates | 📊 P1 | Placement tracking dashboard |
| Reduced mismatch | 🔍 P3 | Gap coverage score per program |
| Better equipment & trainer planning | 💡 P4 | Recommendation types: "Add Equipment", "Train Instructor" |
| Clearer career pathways for candidates | 🎓 P5 | Interest-based + resume-based career path recommendations |

## What Changes From Current Prototype

> [!IMPORTANT]
> **Major scope change**: The current app says "ITI" everywhere. The PS covers ALL skill development — ITI, PMKVY (Pradhan Mantri Kaushal Vikas Yojana), state-level skill missions, NSDC programs, short-term/long-term courses, and private training providers. All branding, data, and language must be broadened.

| Aspect | Current (Wrong) | Corrected |
|--------|----------------|-----------|
| App Name | "SkillBridge — ITI Skill Gap Analyzer" | "SkillBridge — Skill-Market Alignment Platform" |
| Scope | ITI trades only (15) | All skill programs: ITI + PMKVY + state + private (25+) |
| Branding | "ITI Skill Gap" | "Labour-Market Intelligence & Curriculum Alignment" |
| Location focus | Generic India | **Maharashtra** districts (Pune, Mumbai, Nagpur, Nashik, Aurangabad, Thane, Kolhapur, Solapur) |
| Course data | 15 ITI trades | 25+ programs across ITI, PMKVY, state-level, short-term |
| Employer role | Simple approve/reject | Structured validation with industry priority feedback |
| Resume parser | Standalone Groq script | Integrated Gemini-based parser (reference: `resume_parser.txt`) |
| District plans | Not present | District-level recommended training mix |

### Phase 2 — Backend API (New + Modified Endpoints)
